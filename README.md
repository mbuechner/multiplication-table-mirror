# Einmaleins-Spiegel mit Zauberquadraten

Interaktive HTML-Fassung eines historischen Schulwandbilds.

## Start

[`index.html`](index.html) im Browser öffnen. HTML + Vanilla JS. Bootswatch Minty und Bootstrap kommen vom CDN.

## Daten

Beide 9×9-Anordnungen stehen in [`data.js`](assets/js/data.js). Jeder 3×3-Block enthält die Produkte seiner Mittelzahl mit 1 bis 9. Jede Zeile und Spalte im Block ergibt `15 × Mittelzahl`.

## Vorlage

Konkordia AG, Dorfmuseum Schönwalde, Inv.-Nr. 2009-33. [Schulwandbild in der DDB](https://www.deutsche-digitale-bibliothek.de/item/I45H5MDSG2ET62JVCFHEH467ENNZYRLX)
